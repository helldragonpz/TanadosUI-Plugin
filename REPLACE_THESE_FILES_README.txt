Tanados UI settingsPage.js fix - files only package
Version: 2.8.1.1

Problem fixed:
- Jellyfin Web showed: Failed to fetch dynamically imported module: /slider/modules/settingsPage.js
- Root cause in this source version: the settings module loads the language index, and the language index referenced a Bulgarian module name that could be missing/mismatched.

How to apply:
1) Extract this ZIP into the ROOT of your TanadosUI-Plugin source repository.
2) Allow overwrite/replace of existing files.
3) Commit the changes.
4) Build the plugin ZIP again:

   chmod +x scripts/package-tanados-ui.sh
   ./scripts/package-tanados-ui.sh 2.8.1.1

5) Upload dist/TanadosUI-2.8.1.1-server.zip to your GitHub release tag 2.8.1.1.
6) Push the updated manifest.json generated by the build script.
7) In Jellyfin: remove old Tanados UI, restart Jellyfin, install 2.8.1.1, restart Jellyfin.
8) Hard refresh browser: Ctrl + F5. If still cached, clear site data for http://92.10.12.2:8096.
